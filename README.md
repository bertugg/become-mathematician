# Become a Slot Game Mathematician: Ember Forge Project

A 7-session, project-based course. You build and validate the maths model for a fictional slot game.

## Where things are
| File | What it is |
|---|---|
| `PROGRESS.md` | Checklist showing done / current / remaining tasks. **Start here.** |
| `notes/session-NN.md` | Lesson notes, exercises and review feedback for each session |
| `spec/design_brief.md` | Game rules, reel symbol counts, paytable, paylines |
| `notes/setup.md` | One-time development environment setup |
| `ember_forge/` | Your Python code (you write this) |

## How to resume a session
1. Open a terminal in this folder.
2. Pick one:
   - `claude --continue` resumes the last conversation exactly where it stopped.
   - `claude --resume` lets you pick an older conversation from a list.
   - `claude` starts a fresh conversation. Then say: *"Continue the slot math course. Read PROGRESS.md and the latest notes."*
3. Paste or point to your exercise answers. Claude reviews them, writes feedback into the session notes and updates `PROGRESS.md`.

The notes files are the source of truth. Even in a brand-new conversation, they contain everything needed to pick up where you left off.
